Training curve

loss decreases as parameters update

01 · Forward propagation

Each neuron receives weighted inputs, adds a bias, and applies an activation function. The resulting values become the next layer's inputs.

02 · Backpropagation

The prediction error is propagated backward. Gradients indicate how each weight contributed to the error, allowing parameters to be adjusted.

03 · Learning

The learning rate controls the size of each parameter update. More epochs give the optimizer more opportunities to reduce the training loss.
